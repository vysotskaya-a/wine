# Винная подборка — Streamlit

Приложение оценивает вероятность того, что экспертная оценка вина не ниже 7. Оно использует обученный в `HW3_MMDA.ipynb` пайплайн `StandardScaler → LogisticRegression`; обучение в приложении не выполняется.

Проверенная версия интерпретатора: **Python 3.12.3**. Версии библиотек закреплены в `requirements.txt` и совпадают с окружением обучения модели.

## Запуск

Рядом с `app.py` должны находиться `model.joblib`, `config.json` и `test.csv`. Они создаются ячейкой «Сохранение модели» в ноутбуке. Загрузка модели выполняется только из этого локального файла; пользовательские файлы моделей не принимаются.

Из папки `wine_app`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

В Windows окружение активируется командой `.venv\Scripts\activate`. Если окружение уже подготовлено в корне проекта, запуск из корня:

```bash
.venv/bin/python -m streamlit run hw_3/wine_app/app.py
```

Пути к данным строятся от `Path(__file__).resolve().parent`, поэтому запуск не зависит от текущей рабочей папки.

## Возможности

- **Оценка одного вина:** 11 числовых показателей и переключатель цвета. Диапазоны и начальные значения взяты из тестовых данных. Нажмите «Оценить вино» после изменения показателей.
- **Модельные метрики:** матрица ошибок, precision, recall, F1, ROC и PR с точкой текущего порога. Качество оценивается на сохранённой тестовой выборке.
- **Пакетное предсказание:** загрузка CSV, проверка наличия признаков и числовых значений, скачивание прогнозов. `target` нужно убрать; столбец `is_red` содержит только 0 или 1. Пример файла доступен прямо в приложении.
- **Что выучила модель:** коэффициенты при стандартизованных признаках и краткая интерпретация.

Общий порог в сайдбаре хранится в `st.session_state` и действует на всех вкладках. Начальное значение точно берётся из `config.json`. Порог для итоговой модели выбран в ноутбуке на валидации; изменение ползунка на тестовых данных служит демонстрации, а не подбору нового рабочего порога.

## Кэширование

`load_model` использует `st.cache_resource`: модель является готовым ресурсом, один объект которого разделяется между сессиями и повторными запусками скрипта. В приложении его состояние не меняется. Если вызывать `joblib.load` без декоратора, при каждом изменении виджета файл будет читаться и десериализоваться заново.

`load_test_data` и `test_proba` используют `st.cache_data`: таблицы и массивы — результаты вычислений, возвращаемые отдельной копией каждому вызывающему коду. Это защищает кэшированные данные от случайного изменения в другой сессии. Модель передаётся в `test_proba` аргументом `_model`, исключённым из хеширования. В ключ входят данные и время изменения файла модели, поэтому замена модели обновит кэш. Порог не входит в ключ: при его изменении вероятности на тестовой выборке не пересчитываются, меняется только сравнение вероятностей с порогом и производные метрики.

## Публикация в Streamlit Community Cloud

1. Создайте аккаунт [GitHub](https://github.com/signup), если его ещё нет. Создайте репозиторий и загрузите папку `wine_app` со всеми шестью обязательными файлами: `app.py`, `model.joblib`, `config.json`, `test.csv`, `requirements.txt`, `README.md`. Ноутбук и исходные данные также можно разместить в этом репозитории.
2. Зарегистрируйтесь на [share.streamlit.io](https://share.streamlit.io). Можно войти через GitHub; затем отдельно подключите доступ к репозиториям.
3. Нажмите **Create app**, выберите свой репозиторий, ветку и путь к `app.py`. При сохранении текущей структуры проекта путь — `hw_3/wine_app/app.py`; если корень репозитория совпадает с папкой `hw_3`, путь — `wine_app/app.py`.
4. В **Advanced settings** выберите **Python 3.12** и нажмите **Deploy**. Streamlit найдёт `requirements.txt` рядом с `app.py`.
5. После успешного запуска добавьте фактическую ссылку `https://…streamlit.app` в ячейку сдачи ноутбука. До выполнения этого шага облачный деплой не считается завершённым.

Официальная документация: [создание аккаунта](https://docs.streamlit.io/deploy/streamlit-community-cloud/get-started/create-your-account), [деплой](https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy), [кэширование](https://docs.streamlit.io/develop/concepts/architecture/caching).
